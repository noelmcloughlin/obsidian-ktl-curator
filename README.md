# KTL Curator

> "We lasso the world with networks of silver-coloured Italian hemp,\
> We bind down the world into some sort of order;\
> We balance the earth in a pair of scales of our own devising."\
> — Amy Lowell, *The Congressional Library* (1922)

An Obsidian plugin for the person who decides what a **LOKF knowledge bundle** may claim. Open the bundle as a vault, and the plugin says how far each record has been checked, puts the source beside the claim, and writes down what you decide. The status bar reads **Confirmed 12/40**, or, while you edit a concept, that note's own tier beside the count: **Draft · 3/12**. Nothing to configure, no network, no servers.

To install, see [the quick start](https://noelmcloughlin.github.io/obsidian-ktl-curator/docs/install/#quick-start).

> **Only want to ask?** Install `ktl-docent` into any agent you use, by a route from [the install page](https://w3id.org/ktl/docs/install/), and ask it about this project. It answers from the bundle and says how far each answer has been checked.
>
> **Agents:** if `.lokf/knowledge/index.md` exists, read it first; `llms.txt` says how to weigh it.

[The architecture](https://noelmcloughlin.github.io/obsidian-ktl-curator/docs/architecture/) says what a bundle is, which role this plugin plays in keeping one, and how it sits beside your own notes. [Using it](https://noelmcloughlin.github.io/obsidian-ktl-curator/docs/using/) lists the panel, the review card and its five verbs, the in-editor aids, the commands and the settings.

KTL Curator is the **curator**'s assistant from [Knowledge Trust Ladder](https://w3id.org/ktl/): the `ktl-curator` skill's review session, done at a desk in Obsidian instead of in a terminal. Its sibling [KTL Registrar](https://noelmcloughlin.github.io/obsidian-ktl-registrar/) keeps each record well-formed meanwhile. Neither reaches a verdict of its own.
